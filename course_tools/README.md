# ASE 230 Tools - Read in This Order

These materials support the software installation and verification tasks in
HW1. Follow `canvas/homework/HW1/HW1.md` for the graded requirements and exact
verification commands.

## Read the PDFs in This Order

1. `pdf/01. vscode.pdf` - install VS Code and verify its Markdown preview.
2. `pdf/02. install_ase230_tools_with_wsl2.pdf` - Windows only. Install and
   verify WSL2, then use the Ubuntu terminal for course commands. macOS and
   Linux users can skip this file.
3. `pdf/03. php installation.pdf` - install and verify PHP.
4. `pdf/04. mysql installation.pdf` - install and verify MySQL.

`pdf/VS Code Reference.pdf` contains optional VS Code background that is not
required for HW1.

## Directory Structure

- `pdf/` - course instructions to read for HW1
- `code/` - optional helper scripts for VS Code, PHP, and MySQL installation

The helper scripts do not replace the HW1 verification requirements. Read the
matching slide first, run only the script for that topic if desired, and then
run every verification command listed in `HW1.md`.

### Windows Users

Install WSL2 first by following `pdf/02. install_ase230_tools_with_wsl2.pdf`.
Run the PHP and MySQL Linux/WSL2 commands or helper scripts inside the Ubuntu
terminal, not directly in PowerShell or Command Prompt.

## When Something Goes Wrong

Copy the complete error message and note which operating system and command you
used. Contact or visit the professor for help before the HW1 deadline.
