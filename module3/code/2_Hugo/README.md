# Hugo example

Use the lesson slides for the walkthrough. This folder contains the runnable
portfolio example.

```bash
chmod +x run.sh
./run.sh        # build and check the publishable site
./run.sh serve  # preview drafts at http://localhost:1313
./run.sh clean  # remove generated files
```

Edit `my-portfolio/hugo.toml` and the Markdown in `my-portfolio/content/`.
Use your Project 1 API documentation and your own screenshots. Commit source
files only; GitHub Actions generates `public/`.
