Laravel Student API Tests

This page calls the Laravel API (run1-4.sh or run1-6-2.sh) from the browser with fetch(). Each button runs one test. Read the code at the bottom of this file to see how the requests are made.

Configuration

Start the server first: cd student-api && php artisan serve --port=8080

This API has no login: every route is public.

Part 1: Basic Connection Tests

Test 1.1: Server Connection

GET /api/students: can we reach the server and get students?

Test 1.2: API Test Endpoint and Database

GET /api/test returns API information, including the database name.

Part 2: Functional Tests (Unit Test Style)

Test 2.1: Get All Students

GET /api/students returns the expected data structure.

Test 2.2: Get One Student

GET /api/students/{id} returns one student. An unknown id returns 404.

Test 2.3: Create Student

POST /api/students creates a student and returns 201.

Test 2.4: Update Student

PUT /api/students/{id} changes one field. Other fields stay the same.

Test 2.5: Delete Student

DELETE /api/students/{id} removes the student. A later GET returns 404.

Part 3: Error Cases and Extra Endpoints

Test 3.1: Validation Errors

Bad input returns 422 with an errors object. A duplicate email is also rejected.

Test 3.2: Search and Statistics

GET /api/students/search?name=X and GET /api/students/stats.
